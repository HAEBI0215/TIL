# 🧩 정올 문제 풀이

오늘은 **정올 알고리즘 문제**를 풀었다.

단순히 정답을 만드는 것보다
문제를 풀다가 이해가 되지 않는 부분이나 풀이 과정에서 생긴 의문을 질문하면서 진행했다.

특히 문제를 풀 때

> 문제에서 요구하는 것이 정확히 무엇인지 파악하고
> 필요한 로직을 단계별로 나누는 과정

을 계속 연습했다.

문제를 바로 풀 수 없는 경우에도
답을 그대로 가져오기보다는 질문을 통해 필요한 개념과 접근 방향을 확인하고 다시 생각해보는 방식으로 진행했다.

# 💭 문제 풀이 중 질문

오늘 정올 문제를 풀면서
헷갈리는 부분들을 그냥 넘기지 않고 질문하면서 확인했다.

문제를 해결할 때는 단순히

> “이 코드를 어떻게 작성하지?”

만 생각하는 것이 아니라,

* 이 조건이 왜 필요한지
* 현재 접근 방식이 어떤 구조인지
* 문제에서 실제로 요구하는 값이 무엇인지
* 내가 생각한 풀이가 왜 되거나 안 되는지

같은 부분을 확인하는 것이 중요하다는 점을 다시 느꼈다.

아직 문제를 빠르게 푸는 것보다
**풀이 과정을 스스로 이해하는 쪽에 더 집중해서 연습하는 단계**라고 생각한다.

실제로 모르는 내용이나 프로젝트에 활용할 수 있는 부분이 나오는 구간까지 진도를 진행하고 있다.

## 강의 수강 방향

강의를 처음부터 모든 내용을 똑같은 속도로 보는 것보다는

> **이미 알고 있는 내용 → 빠르게 확인하고 넘어가기**
> **모르는 내용 → 멈춰서 제대로 학습하기**

방식으로 진행하는 편이 현재는 더 효율적일 것 같다.

특히 이후에

* Unity 구조
* C# 활용
* 게임 시스템 설계
* 실제 프로젝트 제작 과정

처럼 지금 개발에 직접 사용할 수 있는 내용이 나오기 시작하면
그 부분부터는 조금 더 자세히 볼 예정이다.
